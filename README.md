# 음성 노트 (클로바노트 스타일 웹앱)

녹음하면서 실시간으로 받아쓰고, 음성 파일을 올려 글로 바꾸고, 화자별로 정리하고, AI로 요약하는 단일 HTML 앱입니다. 설치나 서버가 필요 없습니다.

## 실행

`index.html`을 **Chrome 또는 Edge**로 엽니다. 처음 녹음할 때 마이크 권한을 허용하세요.

## 기능

- **음성 파일 업로드 변환**: `⬆ 음성 파일 올리기`로 mp3·m4a·wav·webm·mp4 등을 올리면 AI가 타임스탬프와 함께 받아씁니다. 25MB가 넘는 파일은 브라우저에서 10분 단위로 나눠 보냅니다. 앱에서 녹음한 음성도 `AI 받아쓰기`로 더 정확하게 다시 받아쓸 수 있습니다
- **AI 요약 (Claude)**: 요약 탭의 `AI 요약 만들기`로 한 줄 요약·주요 내용·결정 사항·할 일·확인할 점을 정리합니다. 요약 속 `[mm:ss]`를 누르면 그 위치부터 재생됩니다

- **녹음 + 실시간 받아쓰기**: 한국어·영어·일본어·중국어. 일시정지/계속 녹음 지원
- **화자 구분**: 녹음 중 상단 화자 버튼 또는 숫자키 `1`~`9`로 현재 화자 전환. 녹음 후 화자 이름을 클릭하면 변경, 요약 탭에서 이름 일괄 수정
- **타임스탬프 재생**: 문장의 시간을 누르면 그 위치부터 재생, 재생 중인 문장 강조, 0.75~2배속
- **편집·북마크**: 문장을 직접 클릭해 수정(비우면 삭제), ★로 북마크 후 "북마크만" 보기
- **요약**: 주요 키워드, 핵심 문장(키워드·북마크 기반 자동 추출), 참석자별 발언 비중
- **메모** 탭, 노트 목록 검색, 기록 내 검색
- **내보내기**: TXT 저장, 클립보드 복사, 녹음 파일(webm) 저장

모든 노트와 녹음은 브라우저(IndexedDB)에 저장되며 외부로 업로드되지 않습니다.

## AI 기능 설정

`⚙ 설정`에서 API 키를 입력합니다.

| 기능 | 서비스 | 키 발급 |
|---|---|---|
| 파일 받아쓰기 | OpenAI `whisper-1` 또는 Groq `whisper-large-v3` (Whisper 호환 API라면 주소·모델 직접 입력 가능) | platform.openai.com / console.groq.com |
| AI 요약 | Claude (`claude-opus-5-5`) | console.anthropic.com |

- 키는 이 브라우저의 localStorage에만 저장되고, 음성·기록은 각 서비스로 **직접** 전송됩니다. 공용 PC에서는 사용 후 설정에서 키를 지우세요.
- 사용량에 따라 각 서비스 요금이 부과됩니다.

## 제한 사항

- 받아쓰기는 브라우저 내장 음성 인식(Web Speech API)을 사용합니다. Chrome/Edge에서는 음성이 브라우저 제조사의 인식 서버로 전송되며, 인터넷 연결이 필요합니다. Firefox 등 미지원 브라우저에서는 음성만 녹음됩니다.
- 파일 받아쓰기는 화자를 나누지 않습니다. 결과는 모두 `참석자 1`로 들어가니 화자 이름을 눌러 바꾸세요.
- 25MB가 넘는 파일은 브라우저가 전체를 메모리에 풀어서 나누므로, 아주 긴 파일(수 시간)은 느리거나 실패할 수 있습니다.
- 요약 탭의 키워드·핵심 문장은 AI 없이 기기에서 계산하는 간이 분석이고, `AI 요약`만 Claude를 사용합니다.
- 브라우저 데이터를 삭제하면 노트도 함께 지워집니다. 중요한 기록은 TXT/음성 저장으로 백업하세요.
